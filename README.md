# Site base — Açaí Mania

## Estrutura
- `index.html`
- `style.css`
- `script.js`
- `images/`

## Antes de publicar
1. Abra `script.js`.
2. Troque `SEU_NUMERO_WHATSAPP` pelo número da loja no formato internacional, somente números. Ex.: `5541999999999`.
3. No `index.html`, troque os links `SEU_INSTAGRAM` e `SEU_FACEBOOK`.
4. Coloque as fotos/ilustrações na pasta `images/` usando exatamente estes nomes:
   - acai-banana-leite-condensado.jpg
   - acai-ninho-nutella.jpg
   - banana.jpg
   - leite-em-po.jpg
   - leite-condensado.jpg
   - creme-de-avela.jpg
   - nutella.jpg
   - kit-kat.jpg
   - kinder-bueno.jpg
   - galeria-1.jpg
   - galeria-2.jpg
   - galeria-3.jpg
   - galeria-4.jpg

As imagens dos cards usam proporção 4:3 e as dos adicionais 1:1. O `object-fit: cover` mantém o visual consistente no GitHub/Vercel.
